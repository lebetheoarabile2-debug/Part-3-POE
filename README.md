# TSM Math Club Website

## Project Overview

The TSM Math Club website was developed to create an informative, accessible and engaging online platform for learners interested in improving their Mathematics performance. The website provides information about the Math Club, its programmes and services, learning resources, enquiries and contact information. The overall design was developed to provide a professional academic appearance while still being visually interesting and suitable for the target audience of high school learners.

## What Was Removed

During the development process, unnecessary and repetitive elements were removed to improve the overall structure and usability of the website. Duplicate navigation links and repeated HTML elements were removed where they appeared more than once on a page. Unnecessary code and styling that did not contribute to the final design were also removed. Large video files were excluded from the GitHub repository because they significantly increased the repository size. The videos remain available within the project files, while the GitHub repository contains the website files required for viewing and assessment.

## What Was Improved

Several areas of the original website were improved during development. The navigation system was reorganised to provide clear access to the Home, About, Services, Resources, Contact and Enquiry pages. The website layout was improved to create better spacing, alignment and readability across the different pages. The header was redesigned so that the TSM Math Club logo, title and navigation remain clearly visible while users scroll through the website.

The visual design was also improved through the use of a consistent colour palette consisting of dark blue, lighter blue, gold, cream, grey and white. A background image with a light overlay was introduced to maintain visual interest while ensuring that the written content remains readable. Typography, headings, borders, cards and spacing were adjusted to create a more consistent academic appearance.

The Resources page was improved to organise learning materials in a clearer card-based layout. The Services page was structured to make information about Sunday sessions, grades and available packages easier to understand. The About page was improved through better image placement and content organisation, while the Enquiry page was redesigned to provide a clearer and more user-friendly form.

The website was also improved for responsiveness so that the layout can adapt to different screen sizes. CSS pseudo-classes were incorporated to provide interactive visual feedback when users interact with navigation links and other elements. These improvements were made to enhance usability and provide a more professional user experience.

## What Was Introduced

New and improved features were introduced throughout the website, including a fixed header, responsive layouts, styled navigation links, resource cards, improved forms, consistent page sections and interactive CSS effects. A structured six-page website was implemented consisting of Home, About, Services, Resources, Contact and Enquiry pages.

The website was also connected to GitHub Pages so that the completed project can be accessed online. Git and GitHub were used for version control and to publish the final website. The project README was included to document the development process and explain the major changes made to the website.

## Design and User Experience

The design was developed with the target audience in mind, particularly high school learners who require clear and accessible Mathematics information. The use of whitespace, readable typography, structured sections, visual cards and consistent colours helps users navigate the website without unnecessary complexity. The responsive design also allows the website to adapt to different devices.

The website aims to communicate the TSM Math Club's services in a way that is professional enough for an academic environment while remaining engaging for learners. The combination of educational content, imagery and interactive styling supports the overall purpose of the website.
